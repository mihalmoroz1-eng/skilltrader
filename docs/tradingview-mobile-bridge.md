# Оценка read-only TradingView bridge для мобильного Skill Trader

**Решение на текущем этапе:** мобильный bridge не подключать. Android demo APK не содержит TradingView SDK/MCP, не авторизует TradingView аккаунт и не отправляет запросы к TradingView.

| Вариант | Совместимость с APK | Ограничения | Решение |
| --- | --- | --- | --- |
| `tradingview-mcp-jackson` из видео | Нет прямого подключения: MCP сервер работает через локальный `stdio`, использует запущенный TradingView Desktop и CDP `localhost:9222`. | Присутствуют меняющие действия; часть API недокументирована. CDP нельзя открывать в LAN/Internet или проксировать как удалённый API. | Не переносить в APK и не строить публичный CDP-туннель. |
| Официальный hosted TradingView MCP | Технически это отдельный Streamable HTTP endpoint с OAuth 2.1. | Документирован мобильный сценарий в Claude, но текущие материалы не подтверждают поддержку произвольного клиента Skill Trader; применяются ограничения beta/плана/условий данных. | Не реализовывать custom OAuth client до официального подтверждения допустимого сценария и проверки условий. |
| Собственный read-only адаптер | Потенциально возможен только через отдельно разрешённый TradingView API/источник с лицензией и пользовательским согласием. | Нельзя предполагать право собирать/перераспространять market data. Нужны конкретные API credentials, scopes и retention policy. | Только будущий отдельный проектный этап после проверки лицензии и доступа. |

## Если появится подтверждённый разрешённый вариант

Возможная безопасная схема — Android UI → аутентифицированный HTTPS backend → allow-listed read-only адаптер. Запросы пользователь запускает вручную; разрешены только чтение данных и краткий ответ текущему пользователю. Никаких произвольных MCP tool names, remote URLs, браузерного JavaScript или передачи credentials модели. Отдельно проверить OAuth/PKCE на Android, endpoint origin, scopes, quotas, пользовательские Terms и допустимость конкретного набора данных.

Строгий read-only режим не может наносить уровни на TradingView chart, изменять watchlist/alerts, запускать Pine/replay или делать order execution. Если анализ позднее потребуется, система может показать пользователю текстовые пояснения/синтетические уровни, которые он наносит вручную; без подтверждённого источника не показывать их как реальные рыночные данные.

**Текущая проверка:** GitHub-репозиторий и документация не содержат TradingView credentials; аккаунт пользователя не подключался; CDP порт не открывался. Источники и детали endpoint сохранены в [`mobile-apk-tradingview-research.md`](mobile-apk-tradingview-research.md).
