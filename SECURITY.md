# Политика безопасности

## Поддерживаемые версии

Skill Trader — демонстрационный проект без формального графика релизов. Для рассмотрения исправлений используйте актуальную ветку `main`; отдельные сроки поддержки старых версий не гарантируются.

## Как сообщить об уязвимости

Пожалуйста, не публикуйте сведения об уязвимости, рабочие эксплойты, секреты или персональные данные в открытых issues, pull request или обсуждениях. Если в репозитории включена функция GitHub **Private vulnerability reporting / Report a vulnerability**, отправьте сообщение через неё. Если функция недоступна, свяжитесь с владельцем через доступные приватные контактные ссылки GitHub, не раскрывая детали уязвимости публично.

В отчёте укажите затронутую версию или commit, затронутый компонент, условия воспроизведения, ожидаемое и фактическое поведение, а также возможное влияние. Используйте только синтетические данные. Не проверяйте гипотезы на реальных счетах, котировках, брокерах или чужих пользовательских данных. Не прикладывайте API-ключи, токены, cookies, дампы сессий или рабочие credentials.

Пожалуйста, дайте владельцу разумное время на проверку и подготовку исправления до публичного раскрытия. Фиксированный SLA ответа и координации раскрытия для этого демо не установлен; статус и сроки следует согласовать приватно.

## Границы проекта

Приложение предназначено для учебных синтетических сценариев. Оно не должно выполнять реальные сделки, подключаться к live-рынкам или выдавать персональные торговые рекомендации. Серверные credentials Manus и проектные секреты не являются частью исходного кода и не должны передаваться участникам проекта.
