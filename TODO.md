Безопасный отказ возвращается после второго вызова для не-educational intent или непрошедшей сверки; только согласованный учебный сценарий доходит до третьего вызова выбора 1–3 кодов тем без свободного текста. Между этапами идут только валидированные enum/ID, промежуточные JSON остаются на сервере; ошибка/невалидный output может оборвать цепочку раньше.

При сбое точное число вызовов может быть неизвестно; уже отправленные этапы могут расходовать credits. Внутренние промежуточные результаты не имитируются и не раскрываются.
